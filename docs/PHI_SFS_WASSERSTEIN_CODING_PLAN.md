# Coding Plan: Wasserstein Φ-SFS, Null Replicates, Z-scores, and P-values

## 1. Goal

Replace the current scalar Φ-SFS calculation with the first Wasserstein
distance between two normalized unfolded site-frequency spectra (SFS), then
calibrate the observed TE-to-SNP distance against repeated neutral-to-neutral
comparisons with the same site count and age-matching design.

For one focal TE category, the production result will include:

- the raw observed Wasserstein distance;
- the complete finite-site neutral null distribution;
- a null-standardized Z-score;
- a one-sided add-one Monte Carlo P-value;
- SFS and CDF arrays needed to reproduce the result; and
- diagnostics for direction, matching quality, site count, control reuse, and
  sensitivity to the fixed neutral reference.

This is a breaking statistical change. The implementation must use a new output
schema and must not silently read or combine existing `phi-sfs-v1` results.

## 2. Statistical design

### 2.1 Fixed focal set and matched neutral sets

Let $A$ be the observed focal TE set after all genotype, callability,
polarization, and ARG-quality filters, with exactly $M$ retained sites.

Generate:

- one neutral reference set $B_0$; and
- $R$ neutral comparison sets $B_1,\ldots,B_R$.

Every $B_i$ must:

- contain exactly $M$ retained SNPs;
- match the observed age distribution of $A$;
- use the same individuals and the same filtering, polarization, and
  callability rules as $A$;
- be generated by the same SFS-blind algorithm; and
- be selected without using allele frequencies or Φ-SFS.

Use $R=1000$ for the initial production default. This requires 1001 matched SNP
sets and gives a minimum add-one P-value of $1/1001$.

The primary null holds $A$ and its observed age target fixed. These matched SNP
sets are Monte Carlo neutral replicates. They are not a nonparametric bootstrap
of the TE set.

### 2.2 Relationship to the current bootstrap matcher

`bootstrap_target_matcher.py` currently multinomial-resamples TE sites and
matches each SNP set to a different bootstrapped TE-age CDF. That is useful for
propagating uncertainty in the empirical age target, but it does not implement
the primary null above: it adds target-age bootstrap variation to the
neutral-to-neutral distance.

Add a matcher mode that:

1. uses the observed TE-age CDF for every replicate instead of calling
   `bootstrap_counts()`;
2. generates one reference set plus $R$ comparison sets with independently
   derived random seeds;
3. removes the selected $B_0$ rows from the candidate pool before generating
   any $B_i$; and
4. allows reuse among $B_1,\ldots,B_R$, while measuring and reporting it.

Excluding $B_0$ from every $B_i$ is required. Shared sites within a null pair
would make $\Phi(B_i,B_0)$ artificially small. Reuse among different $B_i$ sets
does not bias an individual distance, but it makes null replicates dependent
and must be reported.

Use a new matcher schema or algorithm version rather than overloading
`bootstrap-target-matches-v1`. A suggested schema is
`phi-null-matches-v1` with metadata fields:

- `reference_replicate_id`;
- `null_replicates`;
- `set_size`;
- `target_age_mode: "observed"`;
- `reference_disjoint_from_null: true`;
- seeds for the reference and every null replicate;
- matching-error and QC arrays; and
- control-reuse summaries.

### 2.3 Equal site count must be enforced upstream

The current `phi_sfs.py` drops sites with fewer than 20 callable individuals
after matching. That can leave $A$, $B_0$, and the $B_i$ with different numbers
of eligible sites, defeating the site-count calibration.

Move eligibility into target and candidate construction:

1. build a reusable VCF eligibility mask using the exact `phi_sfs` genotype and
   callability rules;
2. apply it to the TE target before fixing $M$;
3. exclude ineligible SNPs from the candidate pool before matching; and
4. assert in `phi_sfs.py` that every final set has exactly $M$ eligible sites.

Do not silently downsample all sets to the smallest post hoc count. That would
change the focal set and its age target after matching. A mismatch should fail
with a message directing the user to rebuild the target and controls with the
eligibility mask.

## 3. Core numerical implementation

### 3.1 Preserve projection and normalization

Keep the existing:

- `hypergeometric_projection()`;
- polarity-weighted site projection;
- `(k, n, polarity)` projection cache;
- set-level accumulation; and
- normalization after summing all retained polymorphic mass.

The new statistic operates on the resulting normalized SFS arrays and does not
change their construction.

### 3.2 Replace `PhiResult`

Replace the old residual-mass fields with a result that describes the
Wasserstein calculation and direction diagnostics. For example:

```python
class PhiResult(NamedTuple):
    value: float
    cdf_a: np.ndarray
    cdf_b: np.ndarray
    cdf_residual: np.ndarray
    bin_residual: np.ndarray
    mean_daf_difference: float
```

### 3.3 Implement the one-dimensional distance directly

Add a pure function with no file I/O:

```python
def phi_sfs(
    a: np.ndarray,
    b: np.ndarray,
    *,
    daf: np.ndarray | None = None,
) -> PhiResult:
    ...
```

Validation:

- both inputs are one-dimensional, finite, nonnegative, and have equal length;
- each sums to one within a declared tolerance;
- `daf` is finite and strictly increasing; and
- its length equals the number of SFS bins.

For the default projection, set `daf = RETAINED_BINS / PROJECTION_SIZE`.
Calculate:

```python
cdf_a = np.cumsum(a)
cdf_b = np.cumsum(b)
cdf_residual = cdf_a - cdf_b
value = np.sum(np.abs(cdf_residual[:-1]) * np.diff(daf))
```

The last CDF difference is zero because both spectra sum to one, so it has no
interval to its right. On the equally spaced projected grid, the expression is
equivalent to multiplying the sum of absolute CDF differences by `1 / m`;
including the final zero changes nothing.

Also calculate:

```python
bin_residual = a - b
mean_daf_difference = np.dot(a - b, daf)
```

The Wasserstein distance is unsigned. The mean-DAF difference and residual
arrays provide direction without changing the definition of Φ-SFS.

### 3.4 Implement null calibration as a second pure function

Use a separate result type:

```python
class PhiCalibration(NamedTuple):
    observed: float
    null: np.ndarray
    null_mean: float
    null_sd: float
    z_score: float
    p_value: float
    exceedances: int
```

and function:

```python
def calibrate_phi(observed: float, null: np.ndarray) -> PhiCalibration:
    ...
```

For null distances $D_1^0,\ldots,D_R^0$, calculate:

$$
\mu_0=\frac{1}{R}\sum_i D_i^0,
\qquad
s_0=\sqrt{\frac{1}{R-1}\sum_i(D_i^0-\mu_0)^2},
$$

$$
Z_A=\frac{D_{\mathrm{obs}}-\mu_0}{s_0},
$$

and

$$
P_A=\frac{1+\sum_i\mathbf{1}(D_i^0\ge D_{\mathrm{obs}})}{R+1}.
$$

Implementation details:

- calculate the sample standard deviation with `ddof=1`;
- count ties as exceedances with `>=`;
- use the add-one numerator and denominator exactly as shown;
- require at least two null values for a Z-score;
- reject nonfinite or negative distances; and
- fail if `null_sd` is zero rather than emitting an infinite Z-score.

The function should also return standardized null values
$Z_i^0=(D_i^0-\mu_0)/s_0$ for plotting and later category contrasts.

## 4. Changes to `calculate()`

Refactor the current single loop into these stages:

1. validate provenance and the new null-match schema;
2. load $A$, $B_0$, and $B_1,\ldots,B_R$;
3. scan the VCF once for the union of all requested coordinates;
4. project each distinct site state once;
5. assert that every set has exactly $M$ eligible sites;
6. accumulate and normalize all spectra;
7. calculate
   $D_{\mathrm{obs}}=\Phi_{\mathrm{SFS}}(A,B_0)$;
8. calculate
   $D_i^0=\Phi_{\mathrm{SFS}}(B_i,B_0)$ for every null replicate;
9. call `calibrate_phi()`; and
10. publish all outputs atomically under the new schema.

Keep $B_0$ fixed for every comparison in one analysis. Do not calculate the
observed statistic against the average SNP SFS: that would have a different
finite-sample distribution from each $B_i$-to-$B_0$ null distance.

Vectorize the distance calculation after constructing the SFS matrix:

```python
snp_cdf = np.cumsum(snp_normalized, axis=1)
reference_cdf = snp_cdf[reference_index]
null_cdf = np.delete(snp_cdf, reference_index, axis=0)
null_phi = (
    np.abs(null_cdf[:, :-1] - reference_cdf[:-1])
    * np.diff(daf)
).sum(axis=1)
```

This avoids a Python loop over bins and is trivial in memory relative to the
existing matched-site arrays.

## 5. CLI and configuration

Keep the current required inputs and add:

- `--reference-replicate ID`: optional explicit $B_0$ identifier; default to
  the reference declared by the match bundle, not an implicit array position;
- `--min-null-replicates N`: default 1000 for production, with an explicit
  override for tests and pilots; and
- `--reference-sensitivity N`: optionally repeat calibration for $N$ additional
  prespecified reference sets.

The CLI should fail when:

- the match bundle uses the old schema without an explicit compatibility flag;
- the declared reference is missing or fails QC;
- any null set overlaps $B_0$;
- fewer than the requested null replicates pass matching QC;
- site counts differ after filtering;
- matching used allele-frequency information; or
- the null standard deviation is zero.

Reference selection and QC filtering must occur before reading or calculating
any SFS, preventing outcome-dependent selection.

## 6. Output schema

Use `SCHEMA_VERSION = "phi-sfs-wasserstein-v1"`. Do not reuse a v1 filename
when its meaning changes.

### 6.1 Arrays

Write at least:

- `bins.npy` and `daf.npy`;
- `te_raw_sfs.npy`, `te_normalized_sfs.npy`, and `te_cdf.npy`;
- `snp_raw_sfs.npy`, `snp_normalized_sfs.npy`, and `snp_cdf.npy`;
- `reference_sfs.npy` and `reference_cdf.npy`;
- `observed_phi_sfs.npy`, a scalar array;
- `null_phi_sfs.npy`, length $R$;
- `null_z_scores.npy`, length $R$;
- `observed_bin_residual.npy` and `observed_cdf_residual.npy`; and
- aligned replicate identifier arrays.

### 6.2 Summary table

Write `summary.csv` with one focal-category row containing:

- focal label and target digest;
- $M$ and $R$;
- reference identifier;
- observed Φ-SFS;
- null mean and sample SD;
- Z-score;
- exceedance count;
- add-one P-value and minimum attainable P-value;
- mean-DAF difference; and
- reference-sensitivity range, when requested.

Write `comparisons.csv` with one row for the observed comparison and one row per
null comparison. Include role (`observed` or `null`), both set identifiers,
distance, null Z-score where applicable, site counts, retained/endpoint mass,
matching QC, and reuse diagnostics.

### 6.3 Metadata

Record:

- the exact Wasserstein formula and DAF grid;
- reference-selection rule and seed;
- `ddof=1`, the `>=` tail rule, and the add-one P-value formula;
- requested and accepted null counts;
- all source schema versions and content digests;
- equal-site-count validation;
- whether reference sensitivity was run;
- dependence/reuse diagnostics; and
- complete software and command provenance.

Continue atomic publication and the no-overwrite rule.

## 7. Optional outer TE bootstrap

The core null treats $A$ as fixed. It calibrates finite neutral-sample distance
but does not measure how much the result would change if a different set of TEs
had been observed.

If a confidence interval for the focal statistic is needed, implement it as a
separate outer layer:

1. resample TE sites, preferably by a prespecified genomic block rather than
   iid sites when linkage matters;
2. rebuild that replicate's age target;
3. generate its own $B_0$ and inner neutral sets;
4. recalculate observed Φ-SFS and Z; and
5. summarize the outer distribution with percentile or BCa intervals after
   validating coverage.

Do not use the $B_i$ null distribution as a confidence interval for $A$. The
inner null tests neutral departure conditional on the observed focal set; the
outer bootstrap measures focal-set sampling uncertainty. Because a full nested
bootstrap is expensive, implement and validate the fixed-$A$ analysis first.

## 8. Formal comparisons between TE categories

Put between-category inference in a separate aggregation module so the
single-category calculation remains simple and reproducible.

For categories 1 and 2, calculate:

$$
\Delta_{\mathrm{obs}}=Z_{A_1}-Z_{A_2}
$$

and null contrasts:

$$
\Delta_i^0=Z_{1i}^0-Z_{2i}^0.
$$

If replicate seeds encode a shared bootstrap draw across categories, preserve
that pairing. Otherwise use a prespecified deterministic random pairing and
repeat it as a sensitivity analysis, or use all cross-pairs when feasible.
Calculate the two-sided add-one P-value from
$|\Delta_i^0|\ge|\Delta_{\mathrm{obs}}|$.

Report multiplicity correction for any family of category contrasts. A plot of
two category Z-scores is descriptive until this contrast is performed.

## 9. Test plan

### 9.1 Pure Wasserstein tests

- identical normalized spectra give zero;
- point masses at DAF 0.05 and 0.95 give 0.90;
- moving the same mass twice as far doubles Φ-SFS;
- swapping inputs leaves the scalar unchanged and reverses signed diagnostics;
- direct CDF integration agrees with `scipy.stats.wasserstein_distance` on
  randomized spectra, if SciPy remains an available test dependency;
- irregular DAF grids use `np.diff(daf)` correctly; and
- malformed, negative, nonfinite, or unnormalized inputs fail.

### 9.2 Calibration tests

- a hand-calculated null vector gives the expected mean, sample SD, Z,
  exceedance count, and add-one P-value;
- ties use `>=`;
- the smallest possible P-value is $1/(R+1)$, never zero;
- fewer than two null values and zero null variance fail;
- standardized null scores have mean zero and sample SD one; and
- calibration is invariant to permutation of null replicates.

### 9.3 Bundle and integration tests

- $B_0$ has no row overlap with any $B_i$;
- every set has exactly $M$ eligible sites;
- reference and null identities survive into every output;
- the reference is chosen before SFS calculation;
- old match and output schemas fail clearly;
- fixed inputs and seeds reproduce byte-equivalent numerical arrays;
- atomic output cleanup still works after an injected failure; and
- output arrays independently reproduce summary values.

### 9.4 Statistical validation

Run repeated outer simulations under a neutral exchangeable model and verify:

- Monte Carlo P-values are approximately uniform;
- type-I error is close to the nominal level;
- null Z-scores are centered near zero with unit variance;
- the null mean rises as $M$ decreases, while calibrated type-I error remains
  stable; and
- control reuse and matching error do not inflate false positives.

Under prespecified rare-variant and high-frequency shifts, verify that power and
Z increase with effect size and $M$, while the signed diagnostics recover the
correct direction.

## 10. Implementation sequence

1. Add pure Wasserstein and calibration functions with unit tests.
2. Build the VCF eligibility mask and enforce equal retained site counts.
3. Add the observed-target null mode to the matcher, including reference
   disjointness and the new match schema.
4. Refactor `calculate()` around one reference, $R$ null sets, and vectorized
   distances.
5. publish the new arrays, summary tables, metadata, and schema guards.
6. Replace old end-to-end tests and add statistical calibration tests.
7. Add reference-rotation sensitivity.
8. Add the separate between-category contrast module.
9. Only after the fixed-$A$ route is validated, evaluate an optional outer
   genomic-block TE bootstrap for confidence intervals.

## 11. Acceptance criteria

The revised implementation is ready when:

1. old and new outputs cannot be confused by schema or filename;
2. the direct implementation passes analytic and trusted-library comparisons;
3. every observed and null comparison uses exactly $M$ eligible sites;
4. $B_0$ is selected blindly and is disjoint from every $B_i$;
5. Z and P are reproducible from published raw distances;
6. add-one P-values have validated neutral calibration at relevant site counts;
7. matching error, SNP reuse, and reference sensitivity are reported;
8. the current CLI, README, Slurm launcher, and changelog agree on the new
   semantics; and
9. representative end-to-end runs finish within the current memory and runtime
   envelope before production deployment.
